4)***Three Important Layers -- Controller Layer, Service (Business Logic Layer), Repository (Data Access / Persistence Layer)

a) Controller Layer : Main work of this Controller is accept the request and run the the corresponding services and responds with a Response.
- So when a user hits particular path specified in @RequestMapping("/login") or @GetMapping("/") that purticular method executes and
  give the response. Remember we either give @RestController in a class level or @ResponseBody in the method level.

Step: 1 : create a controller class, define the code using the annotations @RestController or @ResponseBody, @GetMapping or @RequestMapping : com/bhargavspring/demoApp/controller/HomeController.java
Step: 2 : run - com/bhargavspring/demoApp/DemoAppApplication.java
Step: 3 : then go to localhost:8080 and hit the corresponding paths.

c) Repository Layer : The job of this layer is to connect and interact with the database.

* we use Spring Data JPA to send the Requests to H2 Database.
* Add the dependencies "spring-boot-starter-data-jpa" and "h2 runtime".
* And whenever we add the spring data jpa it will ask us the URL to connect with the database, we add that properties in : src/main/resources/application.properties
* Adding the database related manditory configurations
Step: 1 - go to src/main/resources/application.properties
Step: 2 - add "spring.datasource.url" by giving db name, db type
Step: 3 - Access the database : http://localhost:8080/h2-console and in the console url column give spring.datasource.url value specified in
          our application.properties file
